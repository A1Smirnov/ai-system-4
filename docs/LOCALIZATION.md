# Language and data boundaries

Maintained first-party source, interface copy, accessibility labels, comments,
templates and documentation use English. UI dates use en-US formatting while
retaining the configured time zone. The product default is English; an explicit
owner request may choose a different agent response language.

`npm run check:language` audits maintained files for Cyrillic regressions without
printing their contents. It is an editorial aid, not a general language detector.
Multilingual input remains supported through Unicode patterns in privacy/mail
checks. Do not remove those rules when changing presentation language.

Stored/external messages, application forms and evidence retain their original
language. This source edition contains no personal history or configured role
workspaces. Translation grants no permission and does not alter machine status
codes, approval rules or business outcomes.
