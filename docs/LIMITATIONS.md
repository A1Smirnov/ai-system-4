# Scope and remaining work

This snapshot preserves application code, not operational readiness.

- Only four JavaScript modules are under strict TypeScript checking. Declared
  contracts do not prove all producers and consumers agree.
- Some scheduler/resource/learning/shutdown helpers still depend on Windows or
  PowerShell. Historical PowerShell launch scripts and migration repair scripts
  are intentionally omitted. Do not enable background campaigns from this clone.
- Geographic classification remains a US/California implementation with illustrative
  city references. It is not a general worldwide location engine.
- Some OpenClaw adapters depend on internal build filenames and UI markers.
  Revalidate them when changing the pinned runtime.
- Example policy/configuration and model identifiers require local setup. They
  do not reproduce credentials, native agent plugins or complete workspaces.
- The synthetic career fixture checks isolation, deduplication and state handling.
  Its PDF header is not a complete resume or a document-quality test. Real candidate
  truth, form capture completeness and useful application quality need review.
- Multi-process crashes, unknown external outcomes and full private backup/restore
  are not exhaustively verified. No active approval or previous submission is
  included. A draft is not permission to send.
- Dependencies can have advisories; no claim of a clean system or permanent
  security status is made. CI covers development checks, not live integrations.

Export-only edits remove personal labels and candidate assumptions, derive local
paths from the checkout and retain only the plugin build selected by its manifest.
The working installation is unchanged by these edits. Do not overlay this source
edition onto live state as a restore or upgrade procedure.
